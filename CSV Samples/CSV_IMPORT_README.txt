Stobe CSV Startup Import
========================

The Stobe plugin scans this folder on startup:
  mods\Stobe\

Any .csv files found here are uploaded to StobeServer/csv_import.php.

Recommended file naming:
- *_bio_random.csv      -> bio_random_custom
- *_bio_unique.csv      -> bio_unique_custom
- *_bio_token.csv       -> rename_token_global_custom
- *_descriptions.csv    -> descriptions_custom
- *_world_knowledge.csv -> world_knowledge

Sample files included:
- sample_bio_random.csv
- sample_bio_unique.csv
- sample_bio_token.csv
- sample_descriptions.csv
- sample_world_knowledge.csv
