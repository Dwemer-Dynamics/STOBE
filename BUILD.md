# Stobe Build Contract (Locked SDK)

The canonical [build and packaging guide](mod/docs/Stobe/building.md) ships with the plugin. It covers the x64 v100 toolchain, the exact KenshiLib revision, dependency layout, standalone CMake commands, portable tests, and package contents.

The optional `scripts/build-stobe-sdk.ps1` wrapper belongs to the separate Dwemer monorepo and must be run from that monorepo root. It is not a script supplied by this standalone repository.
